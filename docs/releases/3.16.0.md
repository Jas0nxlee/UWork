- 从 v3.15.3 升级继续使用已有 UWork 用户数据；迁移只处理 UWork 自有状态，旧数据根保留。历史 `~/.zcode` 不自动迁移或删除。
- 现有单组织公开登录配置保持兼容。客户端支持多组织配置，不代表已有发布配置已启用三个组织；本次构建的配置数量以 CI 校验日志为准。
