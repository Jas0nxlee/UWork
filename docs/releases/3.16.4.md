## 本次更新

- 修复企业微信扫码时 Main 进程弹出 JavaScript 错误框并卡住的问题：打开、取消、布局更新三个 IPC 入口正确引用同一原生 view owner，保留所属 frame 校验；增加真实 IPC 回调接线回归。

- 安装包验收改用 Chromium CDP 连接未改写的正式包，保留 Windows 的 Node Inspector fuse 关闭；独立原生 view fixture 继续验证窗口归属和回调，测试进程及用户目录完全隔离。

- 修复 Windows 检出时换行转换破坏 Gen UI 固定资源哈希的问题；保持原始资源与 SHA256 校验，并在发布检查中验证 Windows 检出配置。

- 修复子 Agent 启动时报供应商不存在的问题：显式用户目录中的配置与测试样例正确隔离，避免测试将不存在的供应商写入真实用户配置。保留显式模型选择校验，不静默替换用户指定的模型。
- 修复 UWork CLI 日志导出的近 3 天保留窗口，避免过期日志因数据根更名而进入手动导出包；继续排除凭据文件并对诊断内容脱敏。
- 修复上游同步后的集成问题，恢复桌面随包公开登录配置和原生回调归属；插件界面冷启动的瞬态挂载失败可按既有策略恢复。
- 企业身份会话变更时，网关配置只允许当前身份提交，防止迟到请求覆盖新会话配置。
- 非本机回环地址的 HTTP 监听要求有效鉴权，保留本机开发场景的既有边界。
- 更新 UWork 品牌、数据根、MCP 和退役账号链路的回归测试，恢复正常推送前检查。
