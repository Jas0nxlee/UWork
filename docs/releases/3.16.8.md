## 本次更新

- 使用管理员更新后的企业微信公开配置重新构建，为默认公司清单补齐天津登录入口。v3.16.7 发布构建仅包含北京、南京、厦门；公司入口由随包配置决定，服务端接入新组织后仍需重新构建客户端。
- 包含已合并的消息与频道功能、附件处理和未读提醒，以及相关 Office 编辑、模型文件预览、手机远控与服务端随客户端升级的改进。具体可用能力仍取决于企业服务和外部编辑引擎配置。
- 修正原生右键菜单对缺失字段的处理，并整理相关模块边界和回归场景。

## 升级与验证

- 从 3.16.7 升级继续使用现有 `~/.uwork` 数据，不迁移或删除 `~/.zcode`。已有本机 `enterprise-identity.json` 会完整覆盖随包公司清单；管理员自定义的旧清单不会自动合并天津。
- 保留 v3.16.7 的安装包与不可变标签，使用新版本号发布，避免同一版本对应不同安装包。
- 发布沿用类型、Lint、架构、定向回归、生产依赖审计，以及 macOS Apple Silicon / Intel、Windows x64、Linux x64 / ARM64 五平台安装包构建、扫码入口、原生授权页取消和校验和门禁。
- 本次另外核对五平台构建均读取四个组织，并检查实际 macOS 发布包中的天津配置。以上不代表真实天津员工扫码回调、登录成功或全部企业业务已经验收。
- macOS 使用 ad-hoc 签名，未经过 Apple 公证；Windows 不含发布者签名。手机远控和外部 Office 引擎仍需对应服务配置。
