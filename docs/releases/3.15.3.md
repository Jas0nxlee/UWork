## 本次更新

- 修正 macOS DMG 安装窗口背景，中央品牌字样由 `ZCODE` 改为 `UWORK`。
- 同步更新普通与 Retina 背景素材，继续使用将 UWork 拖入 Applications 的安装方式。
- 重新构建 macOS Apple Silicon / Intel、Windows x64、Linux x64 / ARM64 安装包，保留既有行为、安全与新设备扫码入口验证。

## 升级提示

- 从 v3.15.2 升级时，继续使用已有 `~/.uwork` 用户数据。
- 从更早版本升级时，用户级数据使用独立的 `~/.uwork`；旧 `~/.zcode` 不自动迁移或删除，可能需要重新登录、选择工作区与配置个人供应商。
- 历史 MCP OAuth 凭据缺少 issuer 时需重新授权。
- macOS 签名、第三方安全补丁和历史许可材料的说明沿用 v3.15.2：macOS 包未经过 Apple 公证，调试 forge 使用尚未正式发版的固定上游修复提交，许可清单保留历史原文待复核标记。
